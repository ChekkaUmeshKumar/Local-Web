# Usability Log — The 10-Minute Test

The project's success metric: **a first-time user, no tutorial, exports a
working static site in under 10 minutes.** This file records every test
run and what changed because of it.

Protocol (read verbatim to the participant, nothing more):

> "You run a small bakery and want a simple website. Using this app, get a
> finished website file you could put online. You have 10 minutes."

Log per run: date · participant (first-timer?) · pass/fail · time to first
block / first text edit / preview / export · every hesitation, wrong click,
and quoted confusion · what changed afterwards.

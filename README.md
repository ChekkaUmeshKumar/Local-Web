# LocalWeb

A free, open-source desktop app where anyone can drag blocks, edit content, and export a clean static website — in under 10 minutes, no tutorial needed yes no turorial needed.

> **Status:** 🏗️ early development — Phase 1 (Foundation) complete.
> Built with **Tauri 2 · React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · shadcn/ui · Zustand · dnd-kit**.

## Development

Prerequisites: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) (MSVC toolchain), Git.

```bash
npm install
npm run tauri dev      # run the app in dev mode
npm run tauri build   # build the release app + installers
```
